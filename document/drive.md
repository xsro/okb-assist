# 用户网盘（设计与使用）

每个用户拥有一个私有网盘目录；管理员可以创建**公有文件夹**并按**角色阈值**授权读写。
网盘与文献库（上传解析 / 向量索引）**完全独立**，是一个纯粹的文件存放区。

---

## 1. 能做什么

- 私有网盘：上传、下载、在线预览、新建文件夹、重命名、移动、删除（多级目录）；
- 公有文件夹：管理员创建，所有人按配置的角色阈值访问；有写权限的人可以直接往里放文件；
- 配额：默认不限，可按用户单独设置；超配额时上传会被拒绝（只约束私有网盘）；
- 预览：图片（png/jpg/gif/webp/bmp/svg）、PDF、文本/Markdown/代码类文件；其它类型请下载。

入口：顶部导航「网盘」（`/assist/drive`）。

---

## 2. 角色阈值怎么理解

角色等级：`admin(3) > view-upload(2) > view-only(1)`。
用户角色等级 **≥** 文件夹配置的阈值时获得对应权限。

| 配置 | 含义 |
|---|---|
| `read_role = view-only`, `write_role = admin` | 全站可读，仅管理员可写（默认） |
| `read_role = view-only`, `write_role = view-upload` | 全站可读，管理员与「查看+上传」角色可写 |
| `read_role = admin`, `write_role = admin` | 仅管理员可见（对其它角色不可见、不可访问） |
| `read_role = view-only`, `write_role = view-only` | 所有人可读写（谨慎使用） |

> 具体到人：`view-only` 用户在公有文件夹里只能看/下载；自己的私有网盘仍然完全可写。

## 3. 使用方式

### 我的网盘

1. 进入「网盘」→ 左侧「我的网盘」；
2. 「上传文件」或把文件拖到右侧区域（支持多选、显示进度）；
3. 点文件名预览；目录行点名称进入下一级，用面包屑或「返回上一级」回退；
4. 有写权限时每行提供「重命名 / 移动 / 删除」，目录删除会递归删除（有二次确认）；
5. 顶部显示「已用 / 配额」与单文件上限。

### 公有文件夹

左侧「共享（公有文件夹）」里会列出你**能访问**的文件夹，并标注「可写 / 只读」：

- 只读：只能浏览、预览、下载；
- 可写：可以上传、新建文件夹、重命名、移动、删除。

### 预览说明

| 类型 | 行为 |
|---|---|
| 图片 | 模态框内直接显示 |
| PDF | 内嵌 PDF 阅读器（支持 Range 请求） |
| 文本 / Markdown / 代码 | 以等宽字体显示，超过 512KB 只显示前 512KB |
| 其它 | 提示下载 |

## 4. 管理员配置

入口：「网盘」页右上角「管理公有文件夹」（`/assist/drive/admin`，仅 admin）。

### 4.1 网盘设置

| 项 | 说明 |
|---|---|
| 启用网盘 | 关闭后普通用户访问返回「网盘未启用」（数据保留） |
| 单文件上限（MB） | 上传时按此值校验；`DefaultBodyLimit` 在启动时计算，改大后**需重启**才完全生效 |
| 默认配额（MB，0 = 不限） | 对所有用户的私有网盘生效 |

### 4.2 公有文件夹

- 新建：填名称 + 读取阈值 + 写入阈值；
- 列表内可直接改名、改阈值（即时保存）；
- 删除：会**连带删除文件夹内的所有文件**（前端带二次确认，后端要求 `force=1`）。

### 4.3 用户配额

表格里列出每个用户的已用空间与生效配额：

- 在「覆盖值（MB）」里填数字 → 单独设置该用户的配额（`0` 表示该用户**不限**）；
- 点「清除」→ 删除覆盖值，回退到默认配额。

## 5. 存储与运维

```
{drive_root}/users/{user_id}/...       # 私有
{drive_root}/_public/{folder_id}/...   # 公有
```

- `drive_root` 在 `system.json` 中配置（默认 `data/drive`，相对 `cwd`），改后需重启；
- 目录会在首次使用时自动创建；
- 备份：直接备份 `{drive_root}` 目录即可（文件内容与目录结构就是全部数据）；
- 策略（开关 / 上限 / 配额 / 公有文件夹定义）存在 `config.json` 的 `drive` 段，
  只能通过 `/assist/api/admin/drive/*` 修改，配置页不会覆盖它。

## 6. 安全设计

- **私有目录隔离**：`scope=private` 永远绑定当前登录用户，客户端无法指定别人的目录；
- **路径校验**：拒绝 `..`、绝对路径、控制字符、超长名称；拼接后对已存在祖先做
  `canonicalize()`，确保结果仍在作用域根内（防符号链接逃逸）；
- **符号链接**：列目录时跳过，避免逃逸与循环；
- **预览防 XSS**：只有白名单类型（图片/PDF/文本）内联返回，其余强制 `Content-Disposition: attachment`；
  HTML/SVG 不会以可执行上下文渲染（SVG 作为 `image/svg+xml` 但仅在 `<img>` 中使用）；
- **上传原子性**：先写 `.upload-*.part` 再 rename，超限/中断会清理临时文件；
- **配额**：边写边校验，超出立即中止并删除临时文件；
- **审计**：上传、公有文件夹增删改、配额变更都会写入 `audit=drive_*` 日志。

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 提示「网盘未启用」 | 管理员在网盘设置里关闭了功能 |
| 上传返回 413 / 「超过单文件上限」 | 文件超过 `max_upload_mb`；管理员可调大（需重启生效） |
| 上传返回「超出配额」 | 私有网盘超出配额；删除旧文件或让管理员调整 |
| 看不到某个公有文件夹 | 你的角色等级低于该文件夹的 `read_role` |
| 公有文件夹里没有上传按钮 | 你的角色等级低于 `write_role` |
| 删除文件夹提示「目录非空」 | 前端会自动带 `recursive=1`；直接调 API 时需显式传 |
| 下载/预览 401 | token 过期（会话空闲超 7 天）或已登出，重新登录 |
