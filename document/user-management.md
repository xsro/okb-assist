# 用户管理使用指南

面向使用者的说明：如何登录、注册、管理个人令牌，以及管理员如何管理用户。
（实现细节见 `AGENTS.md` 的「用户与认证」一节，升级计划见 `user-management-plan.md`。）

---

## 1. 两类凭证

| 凭证 | 形态 | 用途 | 有效期 |
|---|---|---|---|
| 会话 token | `sess_…` | 浏览器登录态（前端自动带 `X-Token`） | 7 天**滑动**（每次使用顺延，空闲超期才失效）；进程重启后失效 |
| 个人访问令牌 | `okb_…` | Zotero/脚本/MCP 客户端等长期使用 | 长期有效，可随时撤销 |

> 只有哈希落盘：密码是 Argon2id，令牌是 sha256。**令牌明文只在创建时显示一次**。
> 旧版 `system.json` 里的全局凭据（`token` / `mcp_token`）已移除，所有凭据都属于具体用户。

---

## 2. 首次初始化

1. 打开 `/assist/login`，页面显示「系统尚未初始化」，填写用户名/密码即可创建第一个管理员（创建后直接登录）。
2. 创建后请到「账户」页确认密码与个人令牌；管理员在「配置 → 用户管理」页审核后续注册、开启 MCP 访问。

---

## 3. 登录方式

- **账号登录**：用户名 + 密码。
- **注册**：默认开放；新账号状态为「待审核」，管理员通过后才能登录（策略可在用户管理页关闭注册/关闭审核）。
- **Token 登录**：粘贴 `okb_…` 个人令牌或 `sess_…` 会话 token。适合脚本/无密码账号。

登录后右上角显示「显示名 + 角色」，点开可退出登录或去「账户」。

---

## 4. 个人页面（`/assist/account`）

- 查看用户名、显示名、角色、MCP 权限、登录方式、上次登录时间；
- **修改密码**：需要当前密码（若账号还没有密码则可不填）；修改后所有会话被撤销，需要重新登录；
- **个人访问令牌**：
  - 「创建令牌」+ 备注（如 `zotero`）+ **权限二选一**：`API`（调 `/assist/api/*`，Zotero/脚本用）
    或 `MCP`（只能调 `/assist/mcp`），两者**互不通用**；
  - 令牌明文可留空自动生成 `okb_…`，也可自己填一串喜欢的字符串（≥8 位、只能可见 ASCII、
    不能与其他账号重复）；
  - 明文只显示一次，请立即复制；
  - 列表里可随时撤销（撤销后使用该令牌的客户端立即 401）；
  - 权限**不能事后修改**：要改权限请撤销后重新创建。

> 没有 MCP 权限时不能创建 MCP 令牌，需要管理员在「用户管理」里为你的账号打开 MCP。
> 会话 token（密码登录）不受权限限制，既能调 API 也能（在本人有 MCP 权限时）调 MCP。

---

## 5. 管理员：用户管理（配置页 →「用户管理」tab）

> 路径：`/assist/config?tab=users`（旧链接 `/assist/users` 会自动重定向到这里）

| 能力 | 说明 |
|---|---|
| 待审核区 | 一键「通过」或「拒绝（删除）」注册申请 |
| 用户表格 | 直接改角色（管理员 / 只读 / 查看+上传）、启停用、MCP 开关 |
| 重置密码 | 输入新密码；可选「同时撤销全部令牌」；该用户所有会话立即失效 |
| 令牌管理 | 为任意用户签发/撤销令牌（明文只显示一次） |
| 新建用户 | 可设初始密码（留空则该账号只能 Token 登录，需后续重置密码）、角色、状态、MCP |
| 策略 | 开放注册 / 需审核 / 注册默认角色 / 会话有效期（小时） |

**不会把自己锁死**：至少保留一个「启用中的管理员」，最后一个管理员不能降级、禁用或删除（接口返回 409）。

### 角色能力对照

| 角色 | 查看 PDF | 查看 Markdown | 上传 | 编辑/删除 | 配置/管理 |
|---|---|---|---|---|---|
| `admin` | ✅ | ✅ | ✅ | ✅ | ✅ |
| `view-only` | ✅ | ✅ | ❌ | ❌ | ❌ |
| `view-upload` | ❌ | ✅ | ✅ | ❌ | ❌ |

## 6. MCP 使用

```jsonc
{
  "mcpServers": {
    "okb-assist": {
      "url": "http://<host>:5001/assist/mcp/stream",
      "headers": { "Authorization": "Bearer okb_你的个人令牌" }
    }
  }
}
```

- 个人令牌的权限必须是 **MCP**（`scope: mcp`），且账号本身已开启 MCP；API 权限的令牌调 MCP 会返回 401；
- 详情见 `document/mcp.md`。

## 7. 排障

| 现象 | 原因 / 处理 |
|---|---|
| 401 `系统尚未初始化` | 还没有管理员；打开 `/assist/login` 完成初始化 |
| 401 `未授权：无效或缺失的 token` | 会话过期（空闲超过 7 天）、令牌被撤销、或账号被禁用 |
| 登录返回 `账号待管理员审核` | 注册后等管理员通过 |
| 登录返回 `账号因连续登录失败已锁定` | 连续失败 5 次触发退避锁定，等待提示时间或由管理员重置密码 |
| 401 `系统已初始化` 之外提示 | 见上（bootstrap 只能在没有管理员时使用） |
| 忘记管理员密码 | 命令行：`okb_assist --reset-password <用户名> --new-password '<新密码>'` |
| MCP 返回 `MCP access not granted` | 该用户或该令牌未开启 MCP |

## 8. 从旧版本升级（重要）

- `config.json` 的 `permissions` 字典会被**一次性**迁移：每个条目变成一个
  `legacy-<hash 前 6 位>` 占位用户，状态 `pending`、**没有任何凭据**，角色与 mcp 沿用原值；
  迁移后 `permissions` 键从磁盘删除。
- **旧 token 全部失效**（不再接受），需要：
  1. 管理员在「用户管理」里为这些占位用户重置密码（转正），或直接删除；
  2. 依赖旧 token 的脚本/客户端改用新签发的个人令牌。
- `trusted_subnets` 现在默认**不生效**：如确实需要局域网免登录，把 `system.json` 的
  `trusted_subnet_enabled` 设为 `true` 并配置好 `trusted_subnet_role`。
- 旧的问答会话文件（`data/chat_sessions/*.json`）若归属键是 `t:<hash>`（旧格式），
  **仅管理员可见**；新会话按用户归属 `u:<user_id>`。
